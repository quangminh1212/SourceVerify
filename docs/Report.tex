\section{Tổng quan đề tài}

\textbf{Lưu ý:} Bạn có thể xem tổng trang trực tuyến tại \href{https://sourceverify.vercel.app}{\textcolor{AccentBlue}{sourceverify.vercel.app}}.

\textbf{Tên đề tài:} SourceVerify -- Hệ thống phát hiện nội dung do Trí tuệ Nhân tạo tạo ra.

\textbf{Mục tiêu:}
\begin{itemize}
  \item Xây dựng ứng dụng web phát hiện nội dung AI cho ba loại đầu vào: hình ảnh, video và văn bản.
  \item Toàn bộ phân tích chạy trực tiếp trên trình duyệt -- không gửi dữ liệu lên máy chủ, đảm bảo quyền riêng tư.
  \item Các phương pháp phân tích dựa trên bài báo khoa học đã công bố (paper-faithful).
  \item Cung cấp REST API để tích hợp vào hệ thống khác.
  \item Hỗ trợ đa ngôn ngữ: Tiếng Việt, Tiếng Anh và một số ngôn ngữ khác.
\end{itemize}

\section{Các chức năng và Mô-đun dự kiến}

\begin{enumerate}
  \item \textbf{Phân tích hình ảnh} -- phát hiện ảnh AI qua nhiều  phương pháp (phân tích pixel, tần số, texture, metadata, dấu vết GAN/Diffusion).

  \item \textbf{Phân tích văn bản} -- phát hiện văn bản AI qua nhiều phương pháp (entropy, phong cách viết, dấu vân tay mô hình ngôn ngữ).

  \item \textbf{Phân tích video} -- phát hiện video AI qua nhiều  phương pháp (phân tích từng khung hình + lip sync, motion artifact).

  \item \textbf{REST API} -- cho phép tích hợp vào hệ thống khác qua endpoint \texttt{POST /api/analyze}.

  \item \textbf{Giao diện người dùng} -- kéo thả file, nhập URL hoặc văn bản; hiển thị kết quả dạng điểm số và biểu đồ.

  \item \textbf{Đa ngôn ngữ} -- hỗ trợ Tiếng Việt, Tiếng Anh, Hàn, Nhật, Trung.

  \item \textbf{Benchmark tự động} -- đo độ chính xác từng phương pháp trên bộ dữ liệu kiểm thử, công bố kết quả công khai.
\end{enumerate}
